# Security and privacy

## Supported version

Security fixes are applied to the latest release.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not publish exploit details, private listing data, credentials, or client photos in a public issue.

## Privacy boundary

The static editor in `web/` does not upload photos or form data and contains no analytics or remote dependencies. A change that introduces network transmission must be clearly disclosed, disabled by default, and reviewed as a privacy-sensitive change.
